# 安装教程

从零开始，装好就能聊。全程大概 5 分钟。

---

## 需要准备什么

| | |
|---|---|
| **一台安卓手机** | Android 7.0 及以上（2016 年之后的手机基本都满足） |
| **DeepSeek API Key** | 需要自己申请，充几块钱够聊很久 |
| **网络** | 能访问 `api.deepseek.com` 就行 |

**不需要电脑、不需要服务器、不需要额外配置。**

---

## 第一步：申请 API Key

如果你已经有 Key，跳过这步。

### 1. 打开 DeepSeek 开放平台

浏览器访问：**https://platform.deepseek.com**

### 2. 注册 / 登录

用手机号或微信扫码登录。

### 3. 充值

点左侧 **「充值」**，充 **10 元** 就够聊两三个月。

> **为什么必须充值？**
> DeepSeek 的 API 是按 token 计费的，账户余额为 0 时无法调用。
> 充值后余额会显示在左侧。

### 4. 创建 API Key

1. 点左侧 **「API keys」**
2. 点 **「创建 API key」**
3. 名字随便填（比如 `手机`）
4. 点创建
5. **立刻复制那串 `sk-` 开头的字符串**

> ⚠️ **这串 Key 只显示一次**，关掉页面就再也看不到了。
> 先粘贴到备忘录里存好，下一步要用。
>
> 如果没存下来也没关系 —— 删掉那个 Key，重新创建一个就行。

---

## 第二步：下载 APK

### 打开 Releases 页面

**https://github.com/chenzhiqiang2584/dafeiyu-android/releases**

### 找到最新的版本

点开 **「大肥鱼 Android v10.1」**（或者更新的版本）。

### 下载

在页面下方的 **Assets** 里点：

```
dafeiyu-v10.1.apk   6.72 MB
```

**手机会提示下载。**

> 如果手机浏览器提示「此类文件可能有害」，选择 **「仍然下载」** ——
> 这是因为 APK 不是从应用商店安装的，属于正常提示。

---

## 第三步：安装

### 1. 打开下载好的 APK

在手机的文件管理器里找到：
```
Download/dafeiyu-v10.1.apk
```

点它。

### 2. 允许安装

第一次安装会提示 **「禁止安装未知应用」**：

```
┌────────────────────────────────┐
│  为了安全，你的手机目前禁止      │
│  从此来源安装未知应用            │
│                                │
│  [设置]  [取消]                 │
└────────────────────────────────┘
```

1. 点 **「设置」**
2. 打开 **「允许来自此来源的应用」** 开关
3. 返回
4. 再点一次 APK

### 3. 安装

点 **「安装」** → 等几秒 → 点 **「打开」**

> **如果提示「应用未安装」**
> 说明手机上装过签名不同的旧版本。
> 先卸载旧版再装：`设置 → 应用 → 大肥鱼 → 卸载`。

---

## 第四步：填 Key

### 首次启动

打开 App，会看到一个输入框。

### 填入 API Key

把第一步复制的 `sk-` 开头的字符串粘贴进去。

> **点输入框右边的 👁 图标** 可以显示/隐藏 Key，方便检查有没有粘错。

### 保存

点 **「确定」**。

---

## 第五步：开始聊

### 主界面长这样

```
┌────────────────────────────┐
│ 大肥鱼 ●        💬+   ☰   │  ← 顶栏
│ 记忆 0 条 · 历史 0 条 · 直连│
├────────────────────────────┤
│                            │
│              ┌──────────┐  │
│              │ 你是谁    │  │  ← 你的气泡（右）
│              └──────────┘  │
│                            │
│  ┌──────────────┐          │
│  │ 大肥鱼啊      │          │  ← 她的气泡（左）
│  └──────────────┘          │
│                            │
├────────────────────────────┤
│ 说点什么…      😊    ➤     │  ← 输入栏
└────────────────────────────┘
```

### 发第一条消息

在底部输入框打字，点右边的 **蓝色发送键**。

**她会一个字一个字地回复。**

> 第一次回复可能要等 2–5 秒（模型在思考）。

---

## 顶栏三个按钮

| 按钮 | 作用 |
|---|---|
| **💬+** | 新开一个聊天（原来的记录还在） |
| **● 绿点** | 表示已经填了 API Key，能直连 |
| **☰** | 打开设置（所有功能都在这） |

## 常用操作

### 让她记住你

1. 正常聊几轮
2. 点 ☰ → ✨ **AI 分析并提取偏好**
3. 她会总结关于你的偏好，存进记忆
4. 之后聊到相关话题，会自动带上

**查看记住了什么：** ☰ → 🧠 共享记忆与偏好

### 发表情包

点输入框右边的 **😊** 打开表情面板，点一张就发。

**她也会发** —— 聊得合适的时候会自己挑一张。

### 导入自己的表情

表情面板里有 **「＋ 添加」**，可以从相册选图（支持 GIF）。

### 换聊天背景

☰ → 🌄 **换封面**，从相册选一张。

或者 ☰ → 🖼️ **此对话背景设置**，选内置的 12 张之一。

### 开新聊天

点顶栏 **💬+**，或者 ☰ → 🗂️ **切换聊天** → 新开一个。

**每个聊天独立记录，但记忆是共享的。**

### 备份数据

☰ → 📤 **导出全部数据**

会存到：
```
内部存储/Download/大肥鱼备份/
```

**用文件管理器能看到，可以拷到电脑或发给自己。**

### 恢复数据

1. 把 `大肥鱼备份` 文件夹放回 `Download/`
2. ☰ → 📥 **导入数据**

---

## 花钱的事

**每次发消息都要调一次 API，按 token 计费。**

| 场景 | 大概花费 |
|---|---|
| 一轮对话 | 0.001 ～ 0.004 元 |
| 每天 50 轮 | 约 0.18 元 |
| **10 元能用** | **两三个月** |
| 认识表情包（44 张） | 约 0.04 元 |

**随时查余额：** ☰ → ¥ **余额**

**看每轮用了多少：** ☰ → 📈 **Token 统计**

---

## 常见问题

### 提示「余额不足」或「401」

- Key 填错了 → ☰ → 🔑 检查，点 👁 看有没有粘全
- 账户没钱了 → 去 https://platform.deepseek.com 充值
- Key 被删了 → 重新创建一个

### 她说「我出错了」

- 检查网络能不能访问 `api.deepseek.com`
- 有些网络环境会阻断，换个网络试试

### 字体不是行楷

App 用的是自定义字体，**部分系统可能不兼容**。
如果显示成默认字体，不影响使用。

### 装不上 / 安装失败

- **应用未安装** → 先卸载旧版
- **解析包出错** → APK 下载不完整，重新下载

### 聊天记录是空的

**检查一下：**
1. ☰ → 🗂️ 切换聊天，看是不是在当前会话里
2. 当前会话发过消息没有

**新装的 App 从 0 开始记录**，之前的聊天记录不会自动带过来。

### 卸载后数据还在吗

**不在。** 卸载会清空所有本地数据（对话、记忆、设置）。

**想保留先备份：** ☰ → 📤 导出全部数据
